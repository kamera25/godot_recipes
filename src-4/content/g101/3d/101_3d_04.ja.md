前回は、3Dグラフィックスにおいて非常に重要な概念である「トランスフォーム」について学びました。この概念はオブジェクトの空間内での局所的な向きを記録するもので、実際にKinematicBodyキャラクターを動かす際に活用しました。今回は別タイプの3Dノードである{{< gd-icon Area3D >}}`Area3D`について見ていきましょう。

## 区域

{{< gd-icon Area3D >}} `Area3D` ノードは主に以下の目的で使用されます。_検出_ と _影響操作_。オブジェクト同士の重なりを検知したり、特定領域への進入・退出イベントをトリガーできます。また、`Area3D` は物理特性（重力や減衰など）を領域内で上書きするためにも利用できます。

以下のオブジェクトタイプを作成するため、{{< gd-icon Area3D >}}`Area3D` を使用します。

* キャラクターが拾えるコイン
* キャラクターが発射できる弾丸
* 接触するとダメージを受けるスパイク（突起）

まず、衝突判定用のレイヤーを設定して、エリアがどのオブジェクトと相互作用できるかを管理しやすくしましょう。プロジェクト設定を開き、「レイヤー名／3D物理」セクションに移動してください。最初の3つのレイヤーには「環境」「プレイヤー」「収集アイテム」という名前を付けます。

![alt](/godot_recipes/4.x/img/3d_04_01.png)

### コイン数

Kenney Platformer Kit の `CoinGold.glb` オブジェクトから新しい継承シーンを作成します（[パート2](/godot_recipes/4.x/ja/g101/3d/101_3d_02/) 参照）。ルートノードを右クリックし、「タイプを変更」を選択して {{< gd-icon Area3D >}}`Area3D` を選択します。インスペクタで、衝突マスクとレイヤーを設定して、コインが「ピックアップ」として認識され、「プレイヤー」を検出できるようにします。

![alt](/godot_recipes/4.x/img/3d_04_02.png)

Now we need a collision shape, so add a `CollisionShape` node and choose a
`CylinderShape` for it. If you rotate it 90 degrees around **z**, it will fit
the coin shape pretty well.

![alt](/godot_recipes/4.x/img/3d_04_03.png)

スクリプトをエリアに追加し、その `body_entered` シグナルに接続します。このシグナルを使ってコインを削除します。

{{< highlight gdscript>}}
extends Area

queue_free()
{{< /highlight >}}

シーンにコインを数個追加して、拾えるかどうか試してみてください。

![alt](/godot_recipes/4.x/img/3d_04_04.gif)

### 箇条書き項目

Make a new scene with an Area root, and name it "Bullet". Add a `MeshInstance`,
a `CollisionShape`, and a `Timer`. I'm using a sphere shape for the mesh and
collision, scaled to a radius of `0.2` so that it won't be too big compared
with the character. The `Timer` is to give the bullet a time limit. Set its
_One Shot_ and _Autostart_ properties both on.

以下を追加します。

{{< highlight gdscript>}}
extends Area

var speed = 15
var velocity = Vector3()

transform = xform
    velocity = -transform.basis.z * speed

func _process(delta):
    transform.origin += velocity * delta

func _on_Timer_timeout():
    queue_free()

if body is StaticBody:
        queue_free()
{{< /highlight >}}

// プレイヤーの位置から正確に前方へ発射するため、プレイヤーのトランスフォームを start() に渡し、
// これを使用して弾丸の方向を調整し、前進させます (Godot では向きに関して、「前方」は負の z軸方向です)。

これでキャラクターシーンに移動し、`Position3D`ノードを追加できます。このノードは
キャラクターの「矢」メッシュの先端に配置します。このノードは「Muzzle」（銃口）と命名します。次に、以下のコードをキャラクタースクリプトに追加します。

{{< highlight gdscript >}}
var Bullet = プリロード("res://Bullet.tscn")

func _unhandled_input(event):
    if event.is_action_pressed("shoot"):
        var b = Bullet.instance()
        b.start($Muzzle.global_transform)
        get_parent().add_child(b)
{{< /highlight >}}

### スパイク

最後に、環境に危険要素を追加しましょう。`spikes.glb`オブジェクトのインスタンスを作成し、コインと同様にエリアとして設定します。
スクリプトを追加して`body_entered`シグナルに接続しますが、今回はオブジェクトがキャラクターに対して特定のアクションを実行するようにします。

{{< highlight gdscript>}}
extends Area

if body.has_method("take_damage"):
        body.take_attack()
{{< /highlight >}}

現在は、キャラクターが「ダメージ」を受けた時の反応を定義が必要です。健康システム自体はまだ構築していないため、怪我をしたかのように「弾き飛ばされる」動作を実装します。以下の内容をキャラクタースクリプトに追加します。

{{< highlight gdscript>}}
var can_move = true

func take_damage():
    velocity *= -1
    velocity.y = jump_speed
    can_move = false
    yield(get_tree().create_timer(1), "timeout")
    can_move = true{{< /highlight >}}

このコードの目的は、プレイヤーがスパイクから逆方向に飛行するように一時的に入力を無効にすることです。単に速度を直接設定しようとしても、キー操作によって即座に上書きされてしまいます。そこで`get_input()`関数の冒頭部分に以下を追加してください。

{{< highlight gdscript>}}
    if !can_move:
        return
{{< /highlight >}}

レベルにスパイクインスタンスを追加して試してみましょう。
