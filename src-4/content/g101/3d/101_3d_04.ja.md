前回は、3Dグラフィックスにおいて非常に重要な概念である「トランスフォーム」について学びました。この概念はオブジェクトの空間内での局所的な向きを記録するもので、実際にKinematicBodyキャラクターを動かす際に活用しました。今回は別タイプの3Dノードである{{< gd-icon Area3D >}}`Area3D`について見ていきましょう。

## 区域

```
{{< gd-icon Area3D >}} `Area3D` ノードは主に以下の目的で使用されます：_検出_ と _影響操作_。オブジェクト同士の重なりを検知したり、特定領域への進入・退出イベントをトリガーすることができます。また、`Area3D` は物理特性（重力や減衰など）を領域内で上書きするためにも利用可能です。

以下のオブジェクトタイプを作成するため、{{< gd-icon Area3D >}}`Area3D` を使用します：

・キャラクターが拾えるコイン
・キャラクターが発射できる弾丸
・接触するとダメージを受けるスパイク（突起）

まず、衝突判定用のレイヤーを設定して、エリアがどのオブジェクトと相互作用できるかを管理しやすくしましょう。プロジェクト設定を開き、「レイヤー名／3D物理」セクションに移動してください。最初の3つのレイヤーには「環境」「プレイヤー」「収集アイテム」という名前を付けます。

```python
import pygame
from pygmy import Game, Node

class CoinGame(Game):
    def setup_nodes(self, root_node):
        coin_node = Node("Coin")
        coin_shape_node = Node("CollisionShape", parent=coin_node)
        cylinder_shape_node = Node("CylinderShape", parent=coin_shape_node)

        # コインノードに衝突判定用の円筒形を追加
        coin_shape_node.attach_to(root_node)

    def update_nodes(self, root_node):
        coin_node = root_node.find("Coin")
        if coin_node:
            angle = pygame.math.Vector2()
            angle.rotate_ip(90, pygame.math.Vector2.right())  # 回転角度を 90度（z軸周り）に変更

            # 衝突判定用の形状を調整
            coin_shape_node.set_radius(1)  # 半径を 1ユニットに設定
            coin_shape_node.set_height(5)  # 高さを 5ユニットに設定

if __name__ == "__main__":
    game = CoinGame()
    game.run()
```

### スパイク

最後に、環境に危険要素を追加しましょう。`spikes.glb`オブジェクトのインスタンスを作成し、コインと同様にエリアとして設定します。
スクリプトを追加して`body_entered`シグナルに接続しますが、今回はオブジェクトがキャラクターに対して特定のアクションを実行するようにします：

{{< highlight gdscript>}}
extends Area

if body.has_method("take_damage"):
        body.take_attack()
{{< /highlight >}}

現在は、キャラクターが「ダメージ」を受けた時の反応を定義する必要があります。健康システム自体はまだ構築していないため、怪我をしたかのように「弾き飛ばされる」動作を実装します。以下の内容をキャラクタースクリプトに追加します：

{{< highlight gdscript>}}
var can_move = true

func take_damage():
    velocity *= -1
    velocity.y = jump_speed
    can_move = false
    yield(get_tree().create_timer(1), "timeout")
    can_move = true
{{< /highlight >}}

このコードの目的は、プレイヤーがスパイクから逆方向に飛行するように一時的に入力を無効にすることです。単に速度を直接設定しようとしても、キー操作によって即座に上書きされてしまいます。そこで`get_input()`関数の冒頭部分に以下を追加してください：

if not can_move:
        return
{{< /highlight >}}
