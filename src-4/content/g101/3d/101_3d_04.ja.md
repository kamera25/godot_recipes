前回の解説では、3Dグラフィックスにおいて非常に重要な概念である「トランスフォーム」について学びました。これはオブジェクトの空間内でのローカルな向きを記録するもので、これを応用してCharacterBody3Dキャラクターを動かす方法を学びました。今回はもう1種類の3Dノード、「{{< gd-icon Area3D >}}`Area3D`」について詳しく見ていきましょう。

## 区域

{{< gd-icon Area3D >}}`Area3D` ノードは主に以下の目的で使います。_検出_ と _影響操作_。オブジェクト同士の重なりを検知したり、特定領域への進入・退出イベントをトリガーできます。また、{{< gd-icon Area3D >}}`Area3D` は物理特性（重力や減衰など）を領域内で上書きするためにも利用できます。

以下のオブジェクトタイプを作成するため、{{< gd-icon Area3D >}}`Area3D` を使用します。

* キャラクターが拾えるコイン
* キャラクターが発射できる弾丸
* 接触するとダメージを受けるスパイク（突起）

まず、衝突判定用のレイヤーを設定して、エリアがどのオブジェクトと相互作用できるかを管理しやすくします。プロジェクト設定を開き、「レイヤー名／3D物理」セクションに移動してください。最初の3つのレイヤーには「環境」「プレイヤー」「収集アイテム」という名前を付けます。

![alt](/godot_recipes/4.x/img/3d_04_01.png)

### コイン数

Kenney Platformer Kit の `CoinGold.glb` オブジェクトから新しい継承シーンを作成します（[パート2](/godot_recipes/4.x/ja/g101/3d/101_3d_02/) 参照）。ルートノードを右クリックし、「タイプを変更」を選択して {{< gd-icon Area3D >}}`Area3D` を選択します。インスペクターで、衝突マスクとレイヤーを設定して、コインが「ピックアップ」として認識され、「プレイヤー」を検出できるようにします。

![alt](/godot_recipes/4.x/img/3d_04_02.png)

衝突判定用の形状を設定する必要があるため、まず`CollisionShape`ノードを追加し、その中に適切な
`CylinderShape`を選択してください。これを**Z軸**を中心に90度回転させると、コインの形状にほぼぴったりとフィットするようになります。

![alt](/godot_recipes/4.x/img/3d_04_03.png)

スクリプトをArea3Dに追加し、`body_entered`シグナルに接続します。このシグナルを使ってコインを削除します。

{{< highlight gdscript>}}
extends Area3D

func _on_Coin_body_entered(body):
    queue_free()
{{< /highlight >}}

シーンにコインを数個追加して、拾えるかどうか試してみてください。

![alt](/godot_recipes/4.x/img/3d_04_04.gif)

### 箇条書き項目

新規にArea3Dルートを持つシーンを作成し、「Bullet」という名前を付けます。以下のコンポーネントを追加してください：
* `MeshInstance`コンポーネント
* `CollisionShape`コンポーネント
* `Timer`コンポーネント

メッシュと衝突判定には球体形状を使用し、半径を`0.2`にスケーリングしてキャラクターと比較した際に大きすぎないようにしています。`Timer`は弾丸に時間制限を設けるためのものです。以下のプロパティを設定してください：
* _One Shot_ モードを有効にする
* _Autostart_ プロパティを有効にする

スクリプトを追加し、`Timer`の `timeout` シグナルと {{< gd-icon Area3D >}}`Area3D`の `body_entered` シグナルを接続します。次に、以下の内容を追加してください。

{{< highlight gdscript>}}
extends Area3D

var speed = 15
var velocity = Vector3()

func start(xform):
    transform = xform
    velocity = -transform.basis.z * speed

func _process(delta):
    transform.origin += velocity * delta

func _on_Timer_timeout():
    queue_free()

func _on_Bullet_body_entered(body):
    if body is StaticBody:
        queue_free()
{{< /highlight >}}

プレイヤーの位置から正確に前方へ発射するため、プレイヤーのトランスフォームを `start()` に渡し、
これを使用して弾丸の方向を調整し、前進させます (Godot では向きに関して、「前方」は負の z軸方向です)。

これでキャラクターシーンに移動し、`Marker3D`ノードを追加できるようになりました。このノードはキャラクターの「矢印」メッシュの先端に配置してください。このノードは「Muzzle」（銃口）という名前にしましょう。次に、以下のコードをキャラクタースクリプトに追加してください：

{{< highlight gdscript>}}
var Bullet = preload("res://Bullet.tscn")

func _unhandled_input(event):
    if event.is_action_pressed("shoot"):
        var b = Bullet.instantiate()
        b.start($Muzzle.global_transform)
        get_parent().add_child(b)
{{< /highlight >}}

### スパイク

ついに、環境に危険要素を追加してください。`spikes.glb`オブジェクトのインスタンスを作成し、コインと同様にArea3Dとして設定します。
スクリプトを追加して`body_entered`シグナルを接続しますが、今回はオブジェクトがキャラクターに対して特定の動作をさせます。

{{< highlight gdscript>}}
extends Area3D

func _on_Spikes_body_entered(body):
    if body.has_method("take_damage"):
        body.take_damage()
{{< /highlight >}}

現在は、キャラクターが「ダメージ」を受けた時の反応を定義する必要があります。状態システム自体はまだ構築していないため、怪我をしたかのように「弾き飛ばされる」動作を実装します。以下の内容をキャラクタースクリプトに追加してください。

{{< highlight gdscript>}}
var can_move = true

func take_damage():
    velocity *= -1
    velocity.y = jump_speed
    can_move = false
    await get_tree().create_timer(1).timeout
    can_move = true
{{< /highlight >}}

このコードの目的は、プレイヤーがスパイクから逆方向に飛行するように一時的に入力を無効にすることです。単に速度を直接設定しようとしても、キー操作によって即座に上書きされてしまいます。そこで`get_input()`関数の冒頭部分に以下を追加してください。

{{< highlight gdscript>}}
    if !can_move:
        return
{{< /highlight >}}

レベルにスパイクインスタンスを追加して試してみます。
