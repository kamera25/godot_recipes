In the last part, we learned about transforms, a very important concept in 3D that records an object's local orientation in space, and used it to move our CharacterBody3D character. This time, we're going to look at another type of 3D node: the {{< gd-icon Area3D >}}`Area3D`.

## 区域

{{< gd-icon Area3D >}} `Area3D` ノードは主に以下の目的で使用されます。_検出_ と _影響操作_。オブジェクト同士の重なりを検知したり、特定領域への進入・退出イベントをトリガーできます。また、`Area3D` は物理特性（重力や減衰など）を領域内で上書きするためにも利用できます。

以下のオブジェクトタイプを作成するため、{{< gd-icon Area3D >}}`Area3D` を使用します。

* キャラクターが拾えるコイン
* キャラクターが発射できる弾丸
* 接触するとダメージを受けるスパイク（突起）

まず、衝突判定用のレイヤーを設定して、エリアがどのオブジェクトと相互作用できるかを管理しやすくします。プロジェクト設定を開き、「レイヤー名／3D物理」セクションに移動してください。最初の3つのレイヤーには「環境」「プレイヤー」「収集アイテム」という名前を付けます。

![alt](/godot_recipes/4.x/img/3d_04_01.png)

### コイン数

Kenney Platformer Kit の `CoinGold.glb` オブジェクトから新しい継承シーンを作成します（[パート2](/godot_recipes/4.x/ja/g101/3d/101_3d_02/) 参照）。ルートノードを右クリックし、「タイプを変更」を選択して {{< gd-icon Area3D >}}`Area3D` を選択します。インスペクターで、衝突マスクとレイヤーを設定して、コインが「ピックアップ」として認識され、「プレイヤー」を検出できるようにします。

![alt](/godot_recipes/4.x/img/3d_04_02.png)

Now we need a collision shape, so add a `CollisionShape` node and choose a
`CylinderShape` for it. If you rotate it 90 degrees around **z**, it will fit
the coin shape pretty well.

![alt](/godot_recipes/4.x/img/3d_04_03.png)

Add a script to the Area3D and connect its `body_entered` signal, which we'll use
to remove the coin:

{{< highlight gdscript>}}
extends Area3D

func _on_Coin_body_entered(body):
    queue_free()
{{< /highlight >}}

シーンにコインを数個追加して、拾えるかどうか試してみてください。

![alt](/godot_recipes/4.x/img/3d_04_04.gif)

### 箇条書き項目

Make a new scene with an Area3D root, and name it "Bullet". Add a `MeshInstance`,
a `CollisionShape`, and a `Timer`. I'm using a sphere shape for the mesh and
collision, scaled to a radius of `0.2` so that it won't be too big compared
with the character. The `Timer` is to give the bullet a time limit. Set its
_One Shot_ and _Autostart_ properties both on.

以下を追加します。

{{< highlight gdscript>}}
extends Area3D

var speed = 15
var velocity = Vector3()

func start(xform):
    transform = xform
    velocity = -transform.basis.z * speed

func _process(delta):
    transform.origin += velocity * delta

func _on_Timer_timeout():
    queue_free()

func _on_Bullet_body_entered(body):
    if body is StaticBody:
        queue_free()
{{< /highlight >}}

プレイヤーの位置から正確に前方へ発射するため、プレイヤーのトランスフォームを start() に渡し、
これを使用して弾丸の方向を調整し、前進させます (Godot では向きに関して、「前方」は負の z軸方向です)。

Now we can go to the character scene and add a `Marker3D` node, placing it
at the tip of the character's "arrow" mesh. Name this node "Muzzle". Next, add
the following code to the character's script:

{{< highlight gdscript>}}
var Bullet = preload("res://Bullet.tscn")

func _unhandled_input(event):
    if event.is_action_pressed("shoot"):
        var b = Bullet.instantiate()
        b.start($Muzzle.global_transform)
        get_parent().add_child(b)
{{< /highlight >}}

### スパイク

Finally, we're going to add some danger to the environment. Make in instance
of the `spikes.glb` object and make it an Area3D like we did with the coin.
Add a script and connect the `body_entered` signal, but this time, we want
the object to do something to the character:

{{< highlight gdscript>}}
extends Area3D

func _on_Spikes_body_entered(body):
    if body.has_method("take_damage"):
        body.take_damage()
{{< /highlight >}}

現在は、キャラクターが「ダメージ」を受けた時の反応を定義する必要があります。状態システム自体はまだ構築していないため、怪我をしたかのように「弾き飛ばされる」動作を実装します。以下の内容をキャラクタースクリプトに追加します。

{{< highlight gdscript>}}
var can_move = true

func take_damage():
    velocity *= -1
    velocity.y = jump_speed
    can_move = false
    yield(get_tree().create_timer(1), "timeout")
    can_move = true
{{< /highlight >}}

このコードの目的は、プレイヤーがスパイクから逆方向に飛行するように一時的に入力を無効にすることです。単に速度を直接設定しようとしても、キー操作によって即座に上書きされてしまいます。そこで`get_input()`関数の冒頭部分に以下を追加してください。

{{< highlight gdscript>}}
    if !can_move:
        return
{{< /highlight >}}

レベルにスパイクインスタンスを追加して試してみます。
