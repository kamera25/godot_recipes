## キャラクターの追加方法

Now we're going to make a character so we can walk around on the platforms.
Open a new scene and start with a {{< gd-icon CharacterBody3D >}}`CharacterBody3D` named "Character". This `PhysicsBody` node behaves very much like its 2D equivalent (you've already done the 2D tutorials, right?). It has a `move_and_slide()` method that we'll use to perform the movement and collision detection.

```gdscript
extends CharacterBody3D

var gravity = ProjectSettings.get_setting("physics/3d/default_gravity")
var speed = 4.0  # movement speed
var jump_speed = 6.0  # determines jump height
var mouse_sensitivity = 0.002  # turning speed


func get_input():
    var input = Input.get_vector("strafe_left", "strafe_right", "move_forward", "move_back")
    velocity.x = input.x * speed
    velocity.z = input.y * speed

func _physics_process(delta):
    velocity.y += -gravity * delta
    get_input()
    move_and_slide()
```

```c
void _physics_process() {
// 重力を適用して正の Y 軸方向（下向き）に加速させる
    add_to_velocity(GRAVITY * VELOCITY_SCALE, 0.0f);

// get_input() を呼び出して入力状態をチェック
    input_state = get_input();

// 速度ベクトルの方向に移動させるために move_and_slide() を使用
    move_and_slide_with_walls(false, false, false);
}

```
`get_input()` 関数では、押されたキーを確認し、対応する方向に移動します。プログラムを実行してテストしてみましょう：

これは素晴らしい設定ですが、マウスで回転できるようにしたいですよね。キャラクターのスクリプトに以下のコードを追加してください：

```gdscript
func _unhandled_input(event):
    if event is InputEventMouseMotion:
        rotate_y(-event.relative.x * mouse_sensitivity)
```

これにより、x方向のマウス移動はすべて、**y**軸を中心とした回転に変換されます。

シーンを実行し、マウスを動かすとキャラクターが回転することを確認してください：

しかし、問題があります。どちらの方向を向いていようと、**W** を押すと世界の **Z** 軸に沿って移動してしまいます。現在の移動はグローバル座標系に基づいていますが、オブジェクトの進行方向に移動する必要があります。

### 変換の力

```csharp
using System;
using Godot;

public class TransformExample : Node2D
{
    private float _translationX = 0f;
    private float _rotationYaw = 0f;
    private float _scaleX = 1f;

    public override void _Ready()
    {
        // Initializing the transform component
        var transformComponent = GetTransform();

        // Updating the translation based on mouse movement
        transformComponent.Origin.X += _translationX;
        _translationX += GD.GetMouseDeltaY();
    }

    public override void _Process(float delta)
    {
        // Handling rotation around the Y-axis based on mouse wheel scroll
        if (GD.IsScrollingWheel())
        {
            _rotationYaw += delta * 10f; // Adjust speed as needed
        }

        // Scaling the object along the X-axis
        _scaleX += GD.GetMouseDeltaX() / 100f;
        transformComponent.Origin.X *= _scaleX;
    }

    // Accessing the transform properties
    public Vector3 GetTranslation() => transformComponent.Origin;
    public Quaternion GetOrientation() => transformComponent.Basis;
    public float GetScaleX() => _scaleX;
}
```

Remember how the 3D gizmo can be set to "Local Space Mode"? When in this mode,
the gizmo's **X/Y/Z** axes point along the _object's_ axes. This is the same as the `basis` of the transform. The basis contains three `Vector3` objects called `x`, `y`, and `z` that represent these directions. We can use this to ensure that pressing the **W** key will always move us in the object's forward direction.

### カメラ機能の改善

You may have noticed that the if the character stands near an obstacle, the camera can "clip" inside the object, which doesn't look nice. While coding a good 3D camera can be a complex topic on its own, we can use a built-in Godot node to get a pretty good solution.

```markdown
キャラクターシーンから `Camera3D` を削除し、代わりに `SpringArm3D` を追加してください。このノードは移動可能なアームとして機能し、カメラを保持しながら衝突検知を行います。障害物がある場合は、カメラを障害物に近づけるように自動調整します。

プロパティ設定で、**スプリング長さ**を「5」に、**位置**を「(0, 1, 0)」に設定します。これはキャラクターの頭部に位置する値です。**スプリング長さ**を示す黄色のラインに注意してください。カメラはこのラインに沿って移動します - 可能であれば終点まで進み、障害物がある場合はより近付く方向に動きます。

```
{{< gd-icon SpringArm3D >}}`SpringArm3D`の子要素として再び `Camera3D` を追加し、再度ゲームを実行してみてください。スプリングアームを回転させて試してみることができます（例えば**x軸**を中心に少し下向きに調整するなど、好みの配置が見つかるまで自由に操作してください）。
