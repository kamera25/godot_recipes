## プロジェクトマネージャー

「プロジェクトマネージャー」は、Godotを起動したときに最初に表示される画面です。

![alt](/godot_recipes/4.x/img/g4_101_01.png)

In this window you can see a list of your Godot projects. You can choose an existing project and click "Run" to play the game or click "Edit" to work on it in the Godot editor. Since you probably don't have any projects yet, let's start by clicking the "New Project"
button.

<img src=\ alt=\>

ここにプロジェクト名を入力し、保存用のフォルダを作成できます。

{{% notice note %}}
Godot プロジェクトはすべて独自のフォルダ内に格納されます。これには以下のような多くの利点があります：移動や共有、バックアップが容易になることです。また、これはつまり、すべてのプロジェクトファイル（画像、サウンドなど）は必ずプロジェクトフォルダ内に収めなければならないことを意味します。
{{% /notice %} ）

When you're naming your project, try to choose a name that describes the project. "New Game Project #23" is not going to help
you remember what that project was. You should also think about compatibility: some operating systems are case-sensitive, and
some are not. This can lead to problems if you move or share your project from one computer to another. For this reason, many
programmers develop a standardized naming scheme. For example: "No spaces, use '_' between words."

Let's name this new project "getting_started". Type this name, click **Create Folder**, and then click **Create & Edit**.

現在あなたはGodotエディタウィンドウを開いています。これはGodotで作業する際に最も多くの時間を費やす場所です。エディタはセクションに分かれて構成されています。

![alt](/godot_recipes/4.x/img/g4_101_03.png?width=800)

* **ビューポート:** 開発中のゲーム画面が表示される領域です。
* **ワークスペース切り替え:** 上部中央に配置されており、2D/3D/スクリプト各作業環境を簡単に切り替えられます。初期状態では3Dモードが選択されています。
* **プレイテスト用ボタン:** これらのボタンを使用すると、開発中のゲームを起動して操作しながらデバッグできます。
* **ドック/タブパネル:** 左右両側にある複数のドックエリアでは、ゲーム内アイテムを表示し、各種プロパティを設定可能です。
* **下部パネル領域:** ここには各ツールに関連したコンテキスト固有情報が表示されます。特に重要なのは**出力**パネルで、ゲーム実行時にエラーメッセージや動作状況を確認できます。

## プロジェクト設定

神風ウィンドウの主要コンポーネントとその機能について触れたところで、次はプロジェクト設定について少しお話ししましょう。新規プロジェクトを開始する際、まずやるべきことは環境を正しくセットアップすることです。

それでは、メニューの**プロジェクト**をクリックして、**プロジェクト設定**を選択しましょう。

<img src=\ alt=\>

これはプロジェクト設定ウィンドウです。左側にはカテゴリの一覧が表示されます。ほとんどのプロジェクトでは初期設定のままで問題ありませんが、特別なニーズがある場合を除いて、変更する必要はありません。まずは「アプリケーション/設定」セクションから見ていきましょう。まず最初に、「アプリケーション/設定」項目について説明します。

In here, you can set your game's title, choose which scene is the "main scene" (more about that in a bit), and change the icon.

第二に、**表示設定**セクションを確認しましょう。ここではゲームの画面表示を設定します。`width` と `height` パラメータではゲームウィンドウのサイズを指定できます。例えばモバイル向けゲームを開発する場合、対象デバイスの解像度とアスペクト比に合わせてこの値を設定する必要があります。その他にもスケーリング処理や縦横比変更、フルスクリーンモードなどの各種設定が可能です。現時点ではデフォルトサイズのままにしておきますが、後ほど異なるデバイス環境で動作させるための調整方法について詳しく説明します。

![alt](/godot_recipes/4.x/img/g4_101_05.png)

画面上部にはいくつかのタブもあります。これまで「一般」タブについて説明してきましたが、ここで簡単に「入力マップ」についても触れておきます。この機能では、キーボード操作、ゲームパッド、マウスなど、さまざまな入力デバイスに対する個別のアクションを定義できます。実際のゲームプレイ時には、特定のキーやボタンが押されたかどうかを気にする必要はありません。これはプレイヤー入力を扱う上で非常に強力で柔軟な方法です。

また、多言語対応を予定している場合、ローカライゼーション機能もご利用いただけます。後で詳しく説明するオートロード機構やプラグインシステムも用意されています。Godotコミュニティが開発した様々な便利なプラグインをダウンロード・追加することで、さらに多くの機能やツールなどを拡張することが可能です。

プロジェクト設定ウィンドウは後で戻ってきます。今のところ閉じておき、次のステップに進む準備をしましょう。次はノード操作についてです。
