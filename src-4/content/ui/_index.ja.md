# <i class='far fa-window-maximize'></i>&nbsp;UI

Godot 4でゲームUIを構築するための実践レシピです。Controlノード、Container、Label、ボタン、体力表示、クールダウン、選択画面などを使い、解像度に対応するインターフェースを作成します。まず[Container](/godot_recipes/4.x/ja/ui/containers/)で自動レイアウトを学び、[ラベル](/godot_recipes/4.x/ja/ui/labels/)・[ハートコンテナ](/godot_recipes/4.x/ja/ui/heart_containers_3/)・[クールダウンボタン](/godot_recipes/4.x/ja/ui/cooldown_button/)へ進むと、ゲームに必要なUIを段階的に実装できます。
